# 🚀 Projects

## 1. Smart Face Recognition Attendance System

A face-recognition-based attendance system designed to reduce manual attendance work and help prevent proxy attendance.

The system can recognize multiple students through camera input and record attendance automatically.

### Key Features

- Student registration
- Face image collection
- Face detection and preprocessing
- Face recognition
- Multiple-face recognition
- Attendance recording
- CSV attendance export
- Email notification functionality
- Flask-based web interface
- SQLite database

### Technologies

`Python` `Flask` `OpenCV` `MediaPipe` `Scikit-Learn` `NumPy` `Pandas` `SQLite`

### GitHub Repository

## 2. SRM Lab Assistance — Chemistry Lab Assistant

A web-based laboratory assistance platform created for chemistry laboratory experiments.

The application provides students with experiment-related resources such as materials, handwritten notes, procedures, calculations, and experiment information.

Users can enter required values and obtain calculated results based on the experiment.

### Key Features

- Chemistry experiment resources
- Handwritten laboratory notes
- Experiment procedures
- Experiment calculations
- User-input-based calculations
- PDF generation
- Downloadable experiment results

### Technologies

`Python` `Flask` `Flask-CORS` `Matplotlib` `ReportLab`

### GitHub Repository

https://github.com/Shubham-0402/SRM_LAB-Assistance

## 3. Sign Language to Text and Speech

A project focused on converting sign language into text and speech using computer vision and pretrained machine-learning models.

The system uses camera input to capture signs and processes them through a machine-learning pipeline to produce understandable output.

The project explores how AI can help improve communication accessibility in environments such as:

- Banks
- Hospitals
- Offices
- Public service environments

### Technologies

`Python` `Flask` `PyTorch` `Transformers` `Timm` `MediaPipe` `OpenCV` `Scikit-Learn` `XGBoost` `Pandas` `NumPy`

### GitHub Repository

https://github.com/Shubham-0402/sign-language-to-text-and-speech
